## 地图与方法边界

`verified/overlap-detail.png`三列依次为前端、旧后端、新后端，使用相同XY范围及点样式，窗口内全部点显示，不额外对齐。`verified/local-comparisons.png`覆盖四处窗口；其范围、点数记录在audit.json。可见错位结构没有可辨认的收拢，不把所有二维多层结构直接标注成测得重影误差。`verified/pose-changes.png`展示位置/旋转改变量随时间的分布。

两组异步检测时机不同，候选集合并非完全相同；不能用总通过数相减当作严格成对效果。只有单序列各一次运行，不作显著性或跨场景结论。保存旋转矩阵有文本舍入，角度统计先投影到SO(3)。没有独立墙面对应或GT，不能判断所有厘米级变化的正确方向。

两组退出都包含`terminate called without an active exception`及roslaunch的REQUIRED进程死亡记录。保存文件未变、导出结构检查通过，支持分析已保存结果；不等于后端正常退出或内部约束全部消费。44次警告分布在43行日志（存在同一行两次警告），按字符串出现次数计数。
