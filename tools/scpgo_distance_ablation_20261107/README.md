# 最大对应距离150/5/2/1米离线单因素对照

2026-11-07，用户明确批准执行。固定前轮12组配对及已经生成的源/目标点云，单位初值、SC/ICP体素0.4m、100次迭代、两项1e-6停止条件、RANSAC=0不变；仅改变最大对应距离。48次运行完整保留；12组150m得分全部在1e-6容差内复现。未修改生产源码、参数、二进制或回环接受规则，未完整回放SLAM。

## 主要结果

统计口径：近场指标使用固定的“原始源坐标距离≤40m”子集，不按残差裁掉坏点；固定1m内点指最终最近邻距离≤1m，分母为全部源点，仅用于统计。

| 对应距离 | 末段8组固定≤40m点MSE中位数（m²） | 固定1m内点比例中位数 | 原全点规则通过 |
|---|---:|---:|---:|
| 150m | 1.7633 | 33.39% | 0/8 |
| 5m | 0.1264 | 78.22% | 0/8 |
| 2m | 0.2905 | 77.22% | 0/8 |
| 1m | 0.2905 | 77.22% | 0/8 |

每一个末段配对在5/2/1m下的固定近场MSE均低于150m。该受控对照支持：150m过宽会损害这批配对的近场对齐。它不证明较小门限恢复了真实位姿，也不证明5m是通用最优值。

全点fitness变大与近场改善并不矛盾：受限对应的配准不会再为远处不兼容点牺牲局部对齐，但默认评分仍把全部源点计入。不能只看最终“拒绝”就认为缩小对应距离无作用，也不能只把评分改成内点均值就认定闭环可信。

## 异常与限制

- 不存在“越小越好”的单调关系。5→2m时，末段(0,381)的相对变换变化3.136m、14.279°；(7,378)变化0.742m、20.670°。2→1m时7/8组变换相同，但(0,380)仍变化0.491m、10.425°。门限间稳定不等于真实正确；大幅变化则提示对应集合/局部解敏感。
- 对照(0,32)在5→2m时变化13.966m、127.583°；其全点规则始终拒绝。不能把里程计当真值来给这些配对贴真假标签。
- 低分对照(41,151)在四种门限下均为0.01938m²，全部115点在1m内，结果完全相同。缩小对应距离不能独立排除重复结构的近距离误匹配；该配对物理有效性尚未确认。
- PCA轴长只描述内点空间分布，不是ICP信息矩阵，也不能直接宣称某个方向已被证明退化。
- 两个通过对照(41,151)/(135,287)仍通过，另两个对照仍拒绝；末段全部拒绝。没有产生新的完整地图，不能声称重影修复。

## 后续优先项

先核实回访/非回访对照，并离线审查“受限对应评分＋有效匹配数量/比例＋几何分布＋跨帧一致性”的联合验收。评分口径应与参与优化的对应集合相容，但不能单靠删掉大残差获得低分。对门限敏感配对检查对应几何和初值，再判断是否需要多尺度或当前侧短窗多帧。
