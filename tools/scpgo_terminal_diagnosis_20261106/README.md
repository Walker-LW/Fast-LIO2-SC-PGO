# Corridor01 末段几何、初值与对应距离诊断

完成日期2026-11-07；目录沿用跨日前的命名。生产源码、二进制和批准参数均未改。固定12组候选（末段8组、此前两组对照、修正版最低分通过/最大里程计差异通过各一组），比较单位、SC yaw、保存里程计旋转、保存里程计完整位姿四种初值，共48次离线ICP；最大对应距离始终150米、体素0.4米。单位初值的12组得分全部复现上一轮基线。

## 已证实

1. **yaw没有使用。** 当前源码`performSCLoopClosure`只取`detectResult.first`，队列仅存索引；ICP调用`align(output)`未传初值。按当前描述子比较次序，点坐标从当前到历史的旋转应使用返回yaw的负号。已知+30°传感器位姿测试返回330°列移位，取负号恢复误差2.67e-7；不能不验证方向直接传正号。
2. **SC yaw不是本批末段失败的充分解释。** 末段返回0°～42°，补入正确方向yaw后8组仍全部失败。最终(0,382)返回0°，结果完全不变619.9608m²；(0,380)使用-42°初值后227.7453→1388.1015m²。7/8组有2～8个列移位的分数处于全60列最低分+0.01以内；此范围是描述子歧义统计，不是置信区间。保存里程计两种初值也未使任何末段配对通过。
3. **有独立回访证据。** 与关键帧0/375/378/382最近的相机帧（误差小于16ms）都能看到同一标记板和墙角，支持约390～403秒真实回到起始区域。未通过相机标定求得LiDAR点级真值对应，不能把相机回访等同于六自由度充分可观测。
4. **存在近距离几何兼容，但不足以证明正确约束。** 最终当前帧原始1255点，其中1245点在4m内；当前实际ICP源47点，其中37点在4m内、10点超过40m。初始单位变换下37点距历史子地图最近点均小于0.5m。局部原始点云集中在前方少数表面；空间分布和图像支持局部共同可见结构，但重复/平面结构不提供可靠物理对应标签。
5. **150米在这批配对中没有排除任何初始对应。** 末段各组初始最大最近邻距离约41～122米，全部被150米上限保留。最后一组37个近点初始MSE0.07044m²，完整ICP后0.73264m²；10个>40m点贡献初始最近邻平方残差的99.9956%。这是过远对应影响优化的强证据，因果贡献仍需缩小门限的单因素对照确认，不能把这些远点未经核查全部称为传感器噪声。

## 参数与方法的边界

- 对应距离限制的是**变换后的源点与目标对应点之间距离**，不是走廊总长度、子地图半径或传感器量程。室外Riverside02已有定性改善不证明150米适合其精配准，更不能直接迁移到本室内序列。
- `sc_max_radius=40`仅限制描述子编码范围，未过滤ICP输入；远点仍可参与配准。
- 已检查本镜像PCL1.10源码：`getFitnessScore()`默认重新遍历全部源点计算最近邻平方距离，不继承`setMaxCorrespondenceDistance()`。将最大对应距离缩小后，全点分数可能仍很大。下一轮应同时记录原全点分数、固定1m统计口径的内点数量/比例及MSE、近场变化和变换稳定性；本轮未改接受规则。
- 目标目前已经是历史帧±25的子地图；根索引0实际包含0～25共26帧，源仍是单帧。多帧改善应考虑当前侧短窗及局部位姿可靠性，不能简单继续扩大历史窗。
- 多尺度解决初始对齐与分辨率问题，不能创造缺失的几何约束。输入扫描先经SC体素0.4m存储，再经ICP体素0.4m；仅把后级ICP改0.2m无法恢复前级已丢失的点。若实施细尺度，应从保留的原始扫描构建。
- 防误匹配应现在纳入验收：内点数量/比例、空间分布/法向约束、多帧时间一致性及候选物理可信性；不能只看fitness低。图优化Cauchy核不等同于ICP对应点的鲁棒估计。

## 建议的下一项，尚待用户批准

在同一批12组配对、单位初值、0.4m体素及其它参数不变的条件下，只比较最大对应距离**150/5/2/1米**。5米用于保留较大初始容差的过渡对照，2/1米用于检验近场一致性；不是已选定部署值。固定1米内点统计仅用于诊断，不代替0.3m²原接受规则。不同时加入yaw、多尺度、多帧或量程过滤；后续是否需要这些方法由本项对照及几何分布决定。
