晚停尾段40份发布地图每份120186点；所有声明的x/y/z/intensity字段字节一致，位置和强度变化均为0。消息point_step为32，字段偏移0/4/8/16；原始payload有5种哈希，但声明XYZI只有1种哈希，差异位于未声明填充字节。发布图跳帧且排除末节点，不能当成完整离线地图历史。
