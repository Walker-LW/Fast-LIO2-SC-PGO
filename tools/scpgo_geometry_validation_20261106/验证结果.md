# SC-PGO 几何链路隔离验证（2026-11-06）

结论：当前接入机体局部点云的后端存在两项已验证的几何错误：历史子地图未按各帧位姿拼接；ICP 输出转回环约束时方向和坐标表达不一致。不能据此断言它们是 Corridor01 重影的全部原因。

## 验证范围

- 从 Linux 实际源码原样提取 `local2global`、`loopFindNearKeyframesCloud`、`doICPVirtualRelative`，使用现有镜像内 PCL/GTSAM 编译独立程序。只将 ROS 发布器替换为消息捕获器，不启动 ROS、优化线程或原 SLAM 程序。
- 当前源码与参数化编译快照逐字节一致；原后端 SHA256 仍为 `65fbef68a38561c1175fa6947687983a3162dd2d3bf86c487db1e1394b3a94d1`。
- 输入为固定种子生成的 300 个不对称、非共面、间距大于 1 米的点；已知位姿、完整重叠、无噪声。这是确定性正确性测试，不是走廊数据仿真或精度评测。
- 保留 ICP 体素 0.4 米、邻域半宽 25、对应距离 150 米、迭代 100、fitness 阈值 0.3 等默认值。输入 SC 降采样也为 0.4 米。用空槽隔离单帧/三帧输入，当前帧置于索引 51，避免进入历史子地图。
- 预设容差：约束平移 0.001 米、旋转 0.01°、子地图最近邻 RMS 0.001 米。
- 六个预定用例均保留。第二次执行仅添加降采样前与同体素正对照统计，六例与参数不变；首次输出另存为 `first-run-*`。

## 实测

|---|---:|---:|---:|---:|
| 零运动 | 1.40e-12 | 3.25e-8 | 1.20e-5 | 0 |
| 纯平移 | 2.68e-12 | 0.461303 | 6.83e-6 | 0 |
| 平移加旋转 | 3.44e-13 | 0.461298 | 1.853575 | 0 |
| 同上，仅改变公共世界坐标 | 2.01e-12 | 0.435933 | 1.823722 | 3.32e-7 |
| 纯平移，仅改变公共世界坐标 | 8.46e-13 | 0.441934 | 4.95e-6 | 3.32e-7 |
| 三帧子地图，当前与根帧重合 | 6.74e-5 | 0.000449 | 0.007588 | 0.561505 |

六例 ICP 均被原函数接受；四个非零运动单帧用例的约束不正确。三帧例中当前帧与根帧重合，约束误差仍在容差内，但历史子地图已错误叠加；不能把六例都称为约束失败。

纯平移真值为 `(0.18, -0.12, 0.08)` 米，原函数返回约 `(-0.18, 0.12, -0.08)` 米。实际 GTSAM `BetweenFactor(1,51,measurement)` 在真值位姿上的未加权残差亦非零，排除了仅因人工解释约束方向不同造成的误判。

只改变公共世界坐标，真实相对运动不变；原函数的平移测量在混合运动例变化 0.108037 米，纯平移例变化 0.132263 米，违反相对约束的坐标不变性。

三帧子地图原拼接在降采样前 RMS 为 0.561460 米，降采样后 0.561505 米。独立使用各帧已知位姿拼接，并同样进行 0.4 米降采样后，RMS 为 1.86e-7 米。几何错位并非由体素精度造成。

## 源码与坐标关系

实际前端 `publish_frame_body` 发布的是各帧 IMU/body 坐标点云。后端 `process_pg` 对其降采样后直接存入 `keyframeLaserClouds`，未事先统一到历史根帧坐标。

设位姿 `T_p`、`T_c` 将历史/当前机体坐标映射到世界坐标，则 GTSAM 的历史→当前相对位姿测量应为 `Z = inverse(T_p) * T_c`；该矩阵作用于点时，将当前帧点映射到历史帧坐标。

1. 原第 414 行对所有历史帧使用 `T_p`。正确世界坐标拼接需要各帧自己的 `T_j`；若拼到历史帧局部坐标，则需要 `inverse(T_p) * T_j`。
2. 在单历史帧理想情形，原函数先用共同矩阵 `A=T_p` 变换两份局部点云，ICP 得到 `F = A * Z * inverse(A)`，原第 479 行却返回 `inverse(F)`，并在第 691 行放入 `BetweenFactor(previous,current)`。既未消除公共变换，也取了反方向。单帧诊断中用 `inverse(A) * inverse(measurement) * A` 恢复后，非零运动四例误差均小于 1e-6 米、1e-5 度。

上述恢复仅用于定位错误。多帧目标本身已拼错，不能将旧真实数据的回环测量简单取逆后直接复用，必须重建子地图并重新配准。

两个相关表达式在参数化之前的源码快照中已经存在；不是本次 40 米半径、1 米关键帧等参数调整新增的问题。

## 待用户审查的最小修正范围（尚未实施）

采用历史关键帧局部坐标作为目标子地图坐标：

1. 目标的每个历史扫描按 `inverse(T_p) * T_j` 变换后再拼接、降采样。
2. 当前扫描保留自身机体局部坐标；ICP 求当前→历史坐标变换，直接作为 `BetweenFactor(p,c)` 的测量，不再套共同世界变换或取逆。
3. 同步校正调试点云的坐标标注，避免局部点云继续被标作世界坐标。

保留所有现有数值参数、候选检索与优化噪声设置。先让同一组正确性测试通过，再使用保存的真实关键帧检查已接受候选和末段拒绝候选；不能承诺因此自动解决真实走廊的重叠不足、退化或错误候选。

额外发现：`local2global` 的 `numberOfCores=16` 仍是常量；现有 `transform_threads` 控制另一变换函数。此前“全部相关常量已参数化”的表述不完整。这不解释上述几何错误，本轮未修改它。
